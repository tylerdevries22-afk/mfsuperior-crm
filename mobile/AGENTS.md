# Expo SDK 57 Is Required

This project is intentionally pinned to Expo SDK 57. Do not upgrade Expo,
React Native, React, Expo Router, or any aligned Expo package to another SDK
without Tyler's explicit authorization. Read the exact versioned docs at
https://docs.expo.dev/versions/v57.0.0/ before writing mobile code, and keep
`npm run verify:demo` enforcing the SDK 57 release contract.
